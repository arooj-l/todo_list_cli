# Todo List CLI Application

A command-line Todo List application built in Python.  
This project allows users to manage tasks interactively through a menu-driven interface.

## Features

- Add new tasks
- View all tasks with numbering
- Remove tasks safely with validation
- Clear all tasks
- Input validation to prevent crashes
- Continuous loop until user exits

## Concepts Practiced

- Lists and list methods (`append`, `pop`, `clear`)
- Loops (`while True`)
- Conditional statements (`if/elif/else`)
- Exception handling (`try/except`)
- Input validation
- Enumerate function for numbered output
- Basic CLI application structure
- Git branching workflow

## How to Run

1. Make sure Python 3 is installed.
2. Navigate to the project directory.
3. Run: python main.py


## Menu Options

1. Add task  
2. View tasks  
3. Remove task  
4. Exit  
5. Clear all tasks
